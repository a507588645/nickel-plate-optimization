## 说明

- 本报告默认不读取、不统计冻结 test；只有显式 `--include-test` 才会改变该边界。
- `val_letterbox` 口径按 Ultralytics 验证/推理的长边适配估计，适合判断 mAP 验证时目标等效尺寸。

- 小目标尺寸与低 mAP 目前是相关性证据，高分辨率是否提升仍需单变量训练验证。
