## 0. 用户补充后的年度执行策略（2026-09-29 22:42）

### 0.1 固定数据预算修订（22:46，优先于后文资源假设）

用户明确拿不到新数据，只有现有资料。取消补采、新批次、未来三光数据作为年度计划的依赖，不继续等待这些条件。用户未说明能否复核旧图，但主计划不以新增人工标注为启动条件。论文定位调整为固定数据预算下的镍板判级研究，当前建议置信度 Medium，实际收益未知。

1. 主线仍优先电积镍企业等级监督；不得把电解镍规则生成的弱标签当企业真值。先审计已有判级标签和独立组数，再决定折数，不能直接指定五折并保证稀有类覆盖。
2. 评测采用事先冻结的分组嵌套验证：内层用于特征/超参/阈值选择，外层用于冻结流程的比较。物理板、近重复、多光与切片共享 group；缺批次元数据时如实说明代理分组的限制。
3. **必须嵌套整个上游学习流程，不只是 LightGBM。** B3clean 仅按原 grade-test 排除检测器训练重叠；不能把同一个已见新外层验证图的检测器用于全库交叉验证并声称无泄漏。逐折检测器、伪标签教师、特征选择、归一化、PCA、校准都只能拟合对应训练部分；或者采用来源已核验、未在本地评测组训练的固定外部预训练编码器。成本不足时缩小实验，而不是忽略上游泄漏。
4. 既有检测198图 release-validation 继续不访问。其他已分析的历史测试也不能靠重新划分恢复“从未接触”身份；嵌套验证减少后续选模偏差，不能消除历史研究选择偏差。论文报告这一限制，不将内部结果叫外部新批次验证。
5. 首轮基线：多数类/简单统计纹理分类器、冻结外部预训练全局特征、相同编码器的局部特征简单聚合、全局与局部融合。局部候选选择若依赖本地检测器必须先满足上一条；否则用与标签无关的固定多尺度区域作对照。通过信息增量试验后再研究检测可靠性加权/MIL，不一开始堆模块。
6. 固定样本预算下比较25%/50%/75%/100%训练组的学习曲线（均在外层训练内抽样，按稀有类支持量调整，不强行制造覆盖）。报告完整 macro-F1、逐类召回、平衡准确率、校准、风险-覆盖率及计算成本；可做人工光照扰动稳健性测试，但明确是合成扰动，不代表真实新域。
7. 任何图像增强、切片、伪标签都不是新的独立样本；不扩大有效样本量分母。置信区间按独立板组重采样；重复CV的折与seed不当成独立样本做显著性检验。
8. 三光新采集、真实主动补采从执行候选移除；PatchCore只有现有正常样本足够可信时才保留为辅助候选。无额外真值条件下，不以自动修标带来的分数变化认证检测能力提高。

年度时间表保持第5至6个月首投，第4个月的“外部验证”替换为上述内部严格验证、学习曲线与合成扰动实验，公开说明无新批次证据。若用户允许额外使用公开学术数据，可另选任务匹配且许可明确的第二基准，但当前计划不依赖它，也不把跨数据集分数直接排名。

近期交付应是现有数据与上游模型的泄漏矩阵、独立组/类别支持统计、最小公平实验协议；不是立刻运行更多训练。本次仅修订策略，原有数据只读、训练授权与停止规则不变。

## 4. 推荐的三条论文路线

### A. 首选候选：检测引导的多粒度证据融合与风险可控判级

适用：导师允许以工业等级判定为主，已有企业标签可用；暂时不依赖新增逐框标注。适配置信度 Medium，不能保证毕业或发表。

研究问题：在相同数据、分组和特征预算下，局部缺陷视觉证据是否能补足计数/面积/全局纹理的不足，并在相同自动处理覆盖率下减少等级误分？

最小实验按顺序执行，每次只增加一项：

1. 重新建立论文开发/校准/最终测试协议。历史 test 已用于对比与诊断，不再声称它是新方法未接触的确认集；优先取得新批次外部测试。没有新批次时报告探索性分组嵌套验证，不虚称外部泛化。
2. 在同一 detector 和 split 比较：统计特征、纹理特征、两者结合。先拆清既有 33/63 维混杂。
3. 冻结小型视觉编码器，比较全局特征、ROI mean/max 特征、与既有统计特征结合。先用线性分类器等简单基线，不立即训练复杂网络。
4. 只有 ROI 有增量信息，才比较 MIL attention 与相同输入/参数预算的简单聚合。没有检测框的板必须有显式空 bag 或全局回退。
5. 在独立校准部分比较现有置信度拒判、学习型拒判；预先约定覆盖率，测试时不回调阈值。
6. 至少三 seed、组级置信区间；逐类报告、误分代价、端到端延迟。9950/9996 的历史错误只形成假说，不在旧 test 上选择模型。

停止：新特征在开发阶段无一致增量就不做 MIL；新增复杂度无法改善风险-覆盖率或破坏产线延迟预算则保留简单方案。当前真实延迟预算/硬件待确认，不采用旧 Instruction 的 50ms 示例硬套。

可能的贡献是“局部/全局互补证据、缺陷可靠性建模及工业选择性决策的有效性”，不是简单把 DINO+MIL+LightGBM 拼起来。注意力需遮挡/删除实例实验支持解释；多次检索和对照后才能判断新颖性。

### B. 若必须提升检测 mAP：面向漏标和定位不确定性的缺陷检测

适配置信度 Medium；没有可信整图评测真值时无法认证真实收益。

1. 接现有 D0/D1 与 E5a，不另起重复标注任务。
2. 用少量开发试标区分漏标、框边界争议和真正背景误检。13 框只能检验该批候选，不能估全库噪声率。
3. 若漏标主导，优先测试 SparseDet 启发的未标前景保护，而非继续硬加高置信框；与原监督、现有 OOF 硬补标分别比较。
4. 若框误差主导，先用既有 T1 简单定位权重作基线，再研究分类/回归可靠性分开加权；仅排序错误才研究质量重评分。
5. 开发干净子集可受控注入漏框/扰框，验证机制；合成噪声不替代真实企业噪声实验。所有模型共享完整、未变的评测 GT。
6. 原图/板级分组，三 seed；mAP50-95、AP75、逐类召回、FP/板、延迟一起报告。一个主机制通过再扩展，不一次叠三项。

候选题目：“面向不完整标注与定位不确定性的镍板微小缺陷检测方法研究”。这是假说题目，不能预写“显著提升”。

### C. 若三光采集已就绪：可靠性驱动的跨光照缺陷识别

适配置信度 Medium（有配准数据），无硬件/新批次时 Low，不作为唯一毕业依赖。

先验证三通道真实物理语义与配准，再比较单光、拼通道、简单融合、光源可靠性门控；可单独研究某光源饱和/失效时的鲁棒性。单光历史集与三光集按来源分别报告，整板分组，留出未见采集批次。

Real-IAD D3 支持“多模态/光度立体用于工业异常”的研究依据，但其硬件与当前三线线扫不相同。不能将三光拼图叫做已恢复真实三维。MVTec AD2 的未见照明测试为泛化协议提供参考；其异常检测指标不能替代18类框 mAP。

## 5. 两周内的决策方案（非训练排期承诺）

| 阶段 | 交付物 | 继续条件 |
| --- | --- | --- |
| 1：确认约束 | 导师认可的主指标、截止时间、产线延迟/复核预算、标注与补采可得性 | 从 A/B/C 选一条主线，一条备用 |
| 2：零训练诊断 | L1 D0/D1；L2 特征/分组/标签来源审计；已有测试访问记录 | 测量与数据协议可解释 |
| 3：最小试点 | A 仅做简单特征对照；B 仅做误差对应的一种监督改动；C 仅做采集基线 | 单一因素、成本受控，不读旧确认集 |
| 4：继续或停止 | 配对差值、失败案例、资源开销、下一轮预注册 | 开发增量稳定才申请正式三 seed/外部验证 |

阈值需在实验前依波动与工业需求确定。可以把 mAP +0.01 或 macro-F1 +0.02 作为讨论用筛选线，但它们不是显著性标准，更不是预期收益。最终用差值区间、组支持数及生产代价判断。

## 6. 文献证据表

查询日期均为 2026-09-29。论文和同作者代码不是两个独立研究来源。A 的机制由 DINOv2、MIL、SelectiveNet 不同研究分别支持；B 由 SparseDet、Soft Teacher、CLOD 分别支持；C 由 Real-IAD D3 与 MVTec AD2 分别支持。没有任何来源验证本项目的组合收益。

1. [Bolya 等，ECCV 2020，TIDE](https://dbolya.com/tide/)；已读作者页，错误类别及默认 AP50 示例。用途是诊断。
2. [Chachuła 等，2023 v3，Combating noisy labels in object detection datasets / CLOD](https://arxiv.org/html/2211.13993v3)；已读摘要及引言，覆盖 missing/spurious/mislabeled/mislocated。论文自动修正收益不作为本项目预测；代码未验收。
3. [Suri 等，ICCV 2023，SparseDet](https://www.cs.umd.edu/~sakshams/SparseDet/)；已读作者页方法，伪正例挖掘与未标区域自监督；[作者代码](https://github.com/saksham-s/SparseDet)，未运行。
4. [Xu 等，ICCV 2021，Soft Teacher](https://openaccess.thecvf.com/content/ICCV2021/html/Xu_End-to-End_Semi-Supervised_Object_Detection_With_Soft_Teacher_ICCV_2021_paper.html)；已读 CVF 摘要，分类软权重及回归 box jittering；[作者代码](https://github.com/microsoft/SoftTeacher)，未运行。
5. [Li 等，2020，Generalized Focal Loss](https://arxiv.org/html/2006.04388v1)；已读摘要及表示问题分析；[作者代码](https://github.com/implus/GFocal)。不能把已有 DFL 重新包装成创新。
6. [Zhang 等，CVPR 2021，VarifocalNet](https://openaccess.thecvf.com/content/CVPR2021/html/Zhang_VarifocalNet_An_IoU-Aware_Dense_Object_Detector_CVPR_2021_paper.html)；已读 CVF 摘要，IACS 排序与框精修；[作者代码](https://github.com/hyz-xmaster/VarifocalNet)，不是直接可插拔的 YOLO 参数。
7. [Oquab 等，2023，DINOv2 作者代码与模型说明](https://github.com/facebookresearch/dinov2)；已读预训练、线性分类器、模型与许可证部分。推荐普通 DINOv2 小模型冻结特征试点，不从头训练。页面也指向后续 DINOv3，本文未评估其适配，不声称 DINOv2 最新。
8. [Ilse、Tomczak、Welling，ICML 2018，Attention-based Deep Multiple Instance Learning](https://proceedings.mlr.press/v80/ilse18a.html)；已读 PMLR 摘要，bag/instance 和注意力聚合；原文任务不等于工业四等级。
9. [Geifman、El-Yaniv，ICML 2019，SelectiveNet](https://proceedings.mlr.press/v97/geifman19a.html)；已读 PMLR 摘要，联合学习分类与拒判及风险-覆盖率。这里只支持问题设置，不保证生产风险上界。
10. [Zhu 等，CVPR 2025，Real-IAD D3](https://openaccess.thecvf.com/content/CVPR2025/html/Zhu_Real-IAD_D3_A_Real-World_2DPseudo-3D3D_Dataset_for_Industrial_Anomaly_Detection_CVPR_2025_paper.html)；已读 CVF 摘要并获取方法相关检索文本；[数据/代码入口](https://realiad4ad.github.io/Real-IAD_D3)。硬件、异常任务与本项目不同。
11. [MVTec，访问于2026-09-29，MVTec AD2 官方数据页](https://www.mvtec.com/research-teaching/datasets/mvtec-ad-2)；当前页面引用 IJCV 2026 论文，包含未必在训练出现的照明、公开/私有测试与评测服务器，不沿用搜索摘要的模糊年份。
12. [Roth 等，CVPR 2022，PatchCore](https://openaccess.thecvf.com/content/CVPR2022/html/Roth_Towards_Total_Recall_in_Industrial_Anomaly_Detection_CVPR_2022_paper.html)；已读 CVF 摘要，正常局部特征 memory bank；[代码](https://github.com/amazon-science/patchcore-inspection)，未运行。不把 AUROC 99.6% 翻译成检测准确率。
13. [Wang 等，2021/2022，NWD 作者代码](https://github.com/jwwangchn/NWD)；已核对原始论文链接为 arXiv:2110.13389 及2022扩展说明。搜索摘要中其他 arXiv 编号不采纳。

检索质量控制：四次广度检索返回的生成摘要出现“找不到 SparseDet”、NWD 链接冲突和无证据的“最可能最优”判断，均未照抄。通过来源列表找到作者页再验证。Co-teaching、Seesaw、主动学习特定论文等未完成足够原文核查的建议，不列为已验证主参考。没有将企业原图、标签或内部文件上传外部服务。

许可证边界：普通 DINOv2 代码/权重官方 README 标注 Apache-2.0，不外推到其 XRay/Cell 扩展。MVTec AD2 官方明确 CC BY-NC-SA 4.0，限非商业；可考虑合规学术评测，不能默认拿来训练商业交付模型。其余代码、预训练权重和数据必须分别核对许可证后才实施，本轮不作商业授权结论。
