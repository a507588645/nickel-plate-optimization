### 问题原因

原 CSS 中 `.side` 使用 `grid-template-rows: minmax(0,1fr) auto`，底部框列表高度由内容决定。当两侧框数量不同时，底部高度不同，导致上方图片区域高度不同；图片又在区域内垂直居中，于是出现一侧明显偏低的现象。

### 改动

- `generate_paired_yolo_review.py`
  - `.side` 改为 `display:flex; flex-direction:column`。
  - `.viewer` 设为 `flex:1 1 0`，让两侧图片区域强制等高。
  - `.side-bottom` 固定为 `flex:0 0 220px`，内部 `.boxes` 使用 `flex:1` 自动填充并滚动。
  - 为 `.filename`、`.row` 增加 `flex:0 0 auto`，避免被压缩。

### 验证

- `python -m py_compile generate_paired_yolo_review.py` 通过。
- 重新生成 `paired_raw_vs_enhanced/review.html`。
- Playwright 截图验证：低置信度模式下左右两侧图片顶部对齐，底部区域等高。
