### 结论

- 已按 308 分支规则完成电解镍多类 folder 数据集构建，**未改动原 `classify_2types`**，全部通过软连接引用。
- 实际分布：

| 类型 | 含义 | train | valid | 合计 |
| --- | --- | ---: | ---: | ---: |
| 3 | 合格整版 | 911 | 396 | 1307 |
| 4 | 合格600 | 72 | 36 | 108 |
| 0,1,2,5,6 | 无板/3号板/烫洗板/合格不足600/2号板 | 0 | 0 | 0 |

- **关键发现**：`classify_2types` 的 good/bad 二分类与 308 分支的 7 类规则并不对齐。原 `bad` 文件夹中的图片按规则 mostly 仍被判为 type 3 或 4（主要是 A 类小缺陷），没有触发 type 1/2/6 的大面积 B/C 类缺陷条件。
- 因此：**用这个数据集只能训练一个 2 类分类器（type 3 vs type 4），无法替代现有的 7 类硬编码规则**。要训练真正的 7 类分类器，必须额外收集/标注 type 1/2/5/6 的样本。
