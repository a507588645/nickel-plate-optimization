### 改动文件

- 新增 `apply_flat_review_results.py`
  - 读取 `review.html` 导出的 JSONL（`image_name/image_status/box_decisions` 格式）。
  - 默认保留 decision 为 `keep/accepted/uncertain` 的框；`remove/rejected` 丢弃；`pending` 跳过。
  - 若不需要保留 uncertain，加 `--drop-uncertain`。
  - 输出到 `{dataset_root}/{output_suffix}/`（默认 `labels_reviewed_v2/`），不修改 `labels_with_conf/` 主版本。
  - 所有图片都会生成对应 `.txt`，全部被删的图生成空标签文件。
  - 生成 `{output_suffix}_report.json` 统计报告。

### 入口与用法

```bash
python apply_flat_review_results.py \
  --review-result "C:/Users/xxx/Downloads/dianjienie_..._review_result.jsonl" \
  --dataset-root "E:/PythonProject/优化/pseudo_label_datasets/dianjienie_..." \
  --dry-run

# 确认无误后去掉 --dry-run 正式输出
```
