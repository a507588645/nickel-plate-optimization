## 2026-08-22 19:05 | 大文件 *.jsonl.gz 改用 Git LFS 存储

- **执行者**：Kimi Code
- **任务目标**：解决 GitHub 大文件警告（63MB 的 raw tile predictions jsonl.gz 超过 50MB 建议上限）
- **状态**：已完成
- **方案**：方案 A「只对未来生效」——不改写历史、不强推（用户确认）；完整历史迁移（`git lfs migrate import`）作为备选未执行
- **改动文件**：新增 `.gitattributes`（`*.jsonl.gz filter=lfs`）；两个 jsonl.gz 转为 LFS 指针
- **关键命令**：`git lfs install` → `git lfs track "*.jsonl.gz"` → `git rm --cached` + `git add` → commit `5327dde` → push（LFS 上传 89MB）
- **结论**：此后新增/修改的 `*.jsonl.gz` 自动走 LFS；历史提交中的旧 blob 仍在仓库中，体积未缩小
- **风险与待确认**：GitHub 免费 LFS 配额 1GB 存储 / 1GB 月流量，当前占用约 89MB；其他设备 clone 本仓库需装有 git-lfs 才能拿到真实文件
- **下一步**：若未来仓库体积膨胀需彻底瘦身，再评估 `git lfs migrate import --include="*.jsonl.gz" --everything` + 强推
